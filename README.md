# 🤖 AI FAQ Chatbot

A simple AI chatbot built using Flask and TF-IDF similarity from scikit-learn.

This chatbot answers frequently asked questions using Natural Language Processing (NLP).

---

## 🚀 Features

- AI-based FAQ matching
- Flask backend
- Web interface using HTML, CSS and JavaScript
- Custom question dataset
- Fast response system

---

## 🛠 Tech Stack

- Python
- Flask
- Scikit-learn
- Pandas
- HTML
- CSS
- JavaScript

## ⚙️ Installation

Clone the repository

git clone https://github.com/slayxer/ai-faq-chatbot.git

Go to project folder

cd ai-faq-chatbot

Install dependencies

pip install -r requirements.txt

Run the application

python app.py

Open browser

http://127.0.0.1:5000
